IT Ops Center — Incident Management for IT Support Teams

Built end-to-end during the IBM Bob Hackathon following the Explore → Fix → Build methodology, IT Ops Center is a full-stack incident management platform designed for IT support teams.

The platform covers the full incident lifecycle: create, view, search, filter, assign, prioritise, resolve, and close tickets. Each incident includes a notes thread, a troubleshooting actions panel, and a full timeline. An AI troubleshooting panel (powered by a mock provider) surfaces contextual fix suggestions, while an editable incident report feature lets technicians draft and save formal write-ups directly in the app.

Built-in SLA tracking enforces response deadlines by priority — Critical 1 h · High 4 h · Medium 8 h · Low 24 h — computed live at request time so a re-triage to Critical immediately surfaces overdue status. The dashboard exposes overdue counts alongside key stats. A systems page, knowledge base, and settings round out the feature set.

The back end runs on Express with SQLite via Node's native node:sqlite module (requires Node 22.5+), covered by Vitest + Supertest API tests. The front end is React + Vite + Tailwind, served as a static build in production with React Router deep-links supported via an Express fallback.
